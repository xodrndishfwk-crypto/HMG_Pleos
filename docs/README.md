## 전체 완성까지의 순서
[추정] 아래는 앞으로 따라갈 개발 순서다. 완료 표시가 아니라 실행 계획이다.

1. **고사양 PC가 시작 준비**: 최신 코드를 올리고, 세 컴퓨터가 같이 쓸 데이터 형식과 시험 데이터를 준비한다.
2. **세 컴퓨터가 병렬 개발**: 고사양은 화면·차량 연결, 노트북1은 내비, 노트북2는 기록·별자리 기능을 만든다.
3. **노트북1 → 고사양**: 경로·모의주행 기능을 전달한다. 고사양은 지도와 안내 화면에 연결한다.
4. **노트북2 → 고사양**: 기록·방위·저장 기능을 전달한다. 고사양은 별과 정차 액자에 연결한다.
5. **고사양 → 해당 노트북**: 연결 중 발견한 오류를 보낸다. 해당 노트북이 수정해 다시 전달한다.
6. **고사양이 전체 검증**: 내비·별·정차·저장이 하나의 흐름으로 동작하는지 확인한다.
7. **세 컴퓨터가 합의한 나머지 기능 마무리**: 시작 연출·성단·여행 리캡 등 기획 기능을 구현·연결한다.
8. **고사양이 최종 결과 정리**: 검증한 앱, 실행 방법, 남은 제약을 GitHub에 정리하고 최종 인수한다.

## 사람은 무엇을 하면 되나?
[추정] 자기 장비의 실행서를 읽고 AI 지시서를 담당 AI에 전달한다. 작업을 재개할 때는 “GitHub의 docs/README.md와 내 담당 작업을 읽고 다음 단계를 진행해”라고 요청한다.
[추정] 코드 올리기, 테스트 결과 정리, 인수인계 작성, 받은 결과 확인은 담당 AI가 GitHub 접근 권한 안에서 수행한다. 사람이 빈 양식을 직접 채울 필요는 없다. 로그인·접근 권한·실제 기기 연결·제품 결정 등 사람의 행동이 필요한 경우에만 AI가 구체적으로 요청한다.
